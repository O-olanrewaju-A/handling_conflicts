JUMIA NIGERIA-INSPIRED FRONTEND — INTERMEDIATE VANILLA JS

Files
- index.html: page structure and inline SVG iconography
- style.css: responsive layout, styling, hover states and mobile breakpoints
- app.js: sample catalogue, search, category filtering, sorting, carousel, cart, favourites, localStorage, product dialog and demo checkout

Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Run index.html with the Live Server extension, or open index.html directly in a browser.

Design notes
This revision follows the current Jumia Nigeria storefront's visual language more closely: compact utility strip, sticky white header, orange search action, category rail, wide campaign carousel, service panel, quick category tiles, Flash Sales, image-led deal cards and dense product grid. Icons are clean inline SVG line icons (not emoji/cartoon glyphs). Product imagery and campaign photos are remote Unsplash images used as visual placeholders; replace them with licensed Jumia product assets if you have permission to use those assets.

Important
This is an independent learning replica, not Jumia's source code and not affiliated with Jumia. Product images, stock, ratings and prices are sample/demo content. Search, sorting, cart, wishlist, carousel, localStorage and checkout interactions work in the browser. Login and checkout are simulations only; there is no live inventory, account system, payment gateway, delivery integration or backend.

Intermediate coding techniques used
- Arrays and objects for product data
- Reusable rendering functions and template literals
- DOM selection, event delegation and event listeners
- Filtering and sorting
- localStorage persistence
- Responsive CSS Grid/Flexbox and media queries
- Inline SVG icon system
